# BarberBook

Sistema simples de agendamento para barbearia, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Escolha de serviço
- Escolha de data e horário
- Cadastro de nome e WhatsApp
- Salvamento dos agendamentos no LocalStorage
- Área do administrador com login
- Listagem e exclusão de agendamentos
- Layout responsivo

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
